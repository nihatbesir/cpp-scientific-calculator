# cpp-scientific-calculator
English
🌟 Overview & Features
A lightweight, Object-Oriented C++ scientific calculator application running in the command-line interface.

Object-Oriented Architecture: Encapsulates mathematical operations within a clean Calculator class.

Basic Arithmetic Operations: Supports Addition, Subtraction, Multiplication, Division, and Percentage calculations.

Advanced Mathematical Functions: Trigonometric functions (sin, cos, tan), Logarithmic calculations (log10, ln), Powers (x
